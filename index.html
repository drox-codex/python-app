# برنامج بايثون ذكي على الأندرويد
import math

def calculate_pi_power(n):
    return [math.pow(math.pi, i) for i in range(n)]

name = input("ما اسمك؟ ")
print(f"مرحباً {name}! مرحباً بك في Python IDE")

for idx, val in enumerate(calculate_pi_power(3)):
    print(f"π^{idx} = {val:.4f}")

قدرات المطورين

كل ما تحتاجه للبرمجة أينما كنت

تمت هندسة التطبيق ليكون بيئة إنتاجية حقيقية تتجاوز محررات النصوص البسيطة.

محرر أكواد متقدم

تلوين صيغ بايثون كامل، أرقام الأسطر، تراجع وإعادة، بحث واستبدال، وشريط إدخال سريع للأقواس والمسافات والرموز.

محطة أوامر (Terminal)

شاشة سطر أوامر مدمجة بخط Monospace لتنفيذ أوامر Python و Pip وإدارة الملفات وجاهزة للتوصيل بـ Termux.

إدارة حزم Pip

استعراض وتثبيت أشهر مكتبات بايثون (Requests, NumPy, Pandas, Flask) بضغطة زر واحدة مع تتبع الإصدارات.

إدارة الإصدارات (Git)

متابعة التغييرات غير المسجلة، فروع المستودع، تسجيل التعديلات (Commit)، والمزامنة السحابية مع GitHub.

فاحص الأخطاء والمتغيرات

فحص المتغيرات وقيمها وأنواعها في الذاكرة لحظياً مع دعم نقاط التوقف (Breakpoints) والتقدم خطوة بخطوة.

نظام ملفات حقيقي

مشاريع وملفات حقيقية مخزنة على ذاكرة الأندرويد، مع إمكانية استيراد وتصدير مشاريعك بدون قيود مخفية.

محرك CPython 3.12 المدمج (Chaquopy)

تشغيل كود بايثون 3.12 الأصلي مباشرة داخل الأندرويد مع أداء فائق وتكامل عميق مع مكتبات C-Extensions.

جسر المقابس المباشر مع Termux

ربط سداسي مباشر عبر Socket TCP مع بيئة Termux Linux لتنفيذ أي أوامر نظام وتثبيت حزم بايثون المتقدمة.

محرك Git الأصلي (JGit & Libgit2)

إدارة مستودعات حقيقية مع تهيئة .git وفحص الفروقات البرمجية (Diff Viewer) وإنشاء الفروع وسجل التغييرات الكامل.

قارئ ومشغل دفاتر Jupyter (.ipynb)

استعراض وتشغيل ملفات Jupyter Notebook بمرونة، مع تنفيذ الخلايا البرمجية المستقلة وتحرير نصوص Markdown.

محاكاة فورية

جرب بيئة التشغيل مباشرة
